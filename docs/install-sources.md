# Where the launcher downloads from

- App releases come from `https://github.com/storytold/<app>/releases` and GitHub's asset CDN. An approved community app comes from its own repository, pinned in the catalog (`CraftApp::repo`, `AppKind::Community`): today `https://github.com/tangency-labs/solidcraft/releases` (SolidCraft) and `https://github.com/UCS-Care-Group/mailcraft/releases` (MailCraft). `https://github.com/DrDMo/accountingcraft/releases` (AccountingCraft) is proposed, not approved, until a maintainer approves it. The release feed can move an app within `storytold/`, not to another owner.
- A developer's own loopback mirror (`ARTCRAFT_LAUNCHER_DOWNLOAD_BASE`, `cargo xtask local`) is read only by builds with the `local-mirror` cargo feature, which release builds do not enable, and only for loopback addresses.
- Each download is verified against the release's `SHA256SUMS.txt` before it is run or installed, community apps included. On macOS the launcher also requires the Developer ID signature of the app's own team (`CraftApp::mac_team`: ArtCraft's for official apps, SolidCraft's for SolidCraft). An app with `mac_team = None` (today MailCraft and AccountingCraft) is not installed there, only opened if present.
- The details drawer's pictures are JPEGs from a pinned tag of `https://raw.githubusercontent.com/storytold/craft-launcher-assets/` (`core::details`). Each is capped at 2 MB, cached and never run. They are not bundled in this repository.
- Requests send the User-Agent `ArtCraft-Launcher/<version>` and no personal details.
