ArtCraft Launcher is one place to install, update and open the Craft apps, such as PhotoCraft, FilmCraft and VectorCraft.

It lists every app in the suite, shows which ones you have and which version, installs the build that fits your operating system and processor, and tells you when an update is out. It runs on macOS, Windows, Linux and FreeBSD. A web version shows the same list in the browser with download links. The launcher is in early alpha.
