Interface icons
===============

`settings.svg` (the header's Settings button) and `bell.svg` (the header's announcements bell) are
the `settings` and `bell` icons from [Lucide](https://lucide.dev) (lucide-static 0.468.0,
`https://cdn.jsdelivr.net/npm/lucide-static@0.468.0/icons/<name>.svg`), licensed
[ISC](https://github.com/lucide-icons/lucide/blob/main/LICENSE); portions of Lucide come from
Feather (MIT, Cole Bemis). The only changes are `stroke="#ffffff"` instead of `currentColor`, so the
app can tint them to the theme, and the `class` attribute removed.

`apple.svg`, `windows.svg`, `linux.svg` and `freebsd.svg` are from [Simple Icons](https://simpleicons.org/)
11.10.0 (`https://cdn.jsdelivr.net/npm/simple-icons@11.10.0/icons/<name>.svg`), released under
[CC0 1.0](https://github.com/simple-icons/simple-icons/blob/11.10.0/LICENSE.md). The root fill is white
so the launcher can tint the icons. The logos identify the platforms listed in app details.
